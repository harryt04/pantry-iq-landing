## Q1: Impact Calculation — Which Costs to Include?

**Context:** We're calculating financial impact to rank dashboard alerts. We need to know which cost categories to include.

**Question:** Which of these should be included in the Impact score for MVP?
- Current spoilage risk (on-hand inventory × unit cost)
- Historical spoilage (past weeks' waste × unit cost)
- Overordering cost (excess inventory carrying cost)
- Margin loss (low-selling items' margin impact)

Should all be included equally, or should spoilage be the primary driver? Should we allow the user to tune these calculation weights for their business, or is this calculation standard industry wide?
